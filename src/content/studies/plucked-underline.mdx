## A string tuned by its length

A string's pitch depends on its length, tension, and mass per unit length: f = (1/2L)·√(T/μ). With the same tension and gauge, a longer string vibrates more slowly and rings longer. Each underline here is a string the length of its link.

The motion is one `linear()` curve, a damped oscillation sampled into evenly spaced stops. JavaScript measures each underline and sets its duration to 13ms per pixel, clamped between 400ms and 1200ms. The same 2.4 cycles stretch over more time, so a long link swings slower and settles later. The bend follows the same rule: its depth is the width ÷ 18, between 2px and 5px.

## Flatten the bend, keep the path

The underline is one quadratic curve whose control point holds the bend, and its `d` attribute never changes while it moves. `scaleY()` presses the curve toward the rest line. When the easing overshoots past 1, the scale goes negative and the bend swings above the line before it settles.

`vector-effect: non-scaling-stroke` keeps the stroke at 1.5px while the shape is squeezed. The transform ends at `scaleY(0.001)` because at 0 there is nothing left to stroke.

## Pluck where the pointer enters

On `pointerenter`, the script moves the control point to where the pointer crossed the underline, between 15% and 85% of its width. The underline opens outward from there in 140ms. When the pointer leaves, it closes back into the same point in 110ms while the string keeps ringing.

A `data-plucked` attribute opens the underline. With `:hover`, the transition would start from the previous pluck point. The script commits the new starting state with transitions off and then sets the attribute, so each pluck starts clean even while the last one is still ringing. A separate `data-ringing` attribute lets the underline close without freezing the string mid-swing.

## Keyboard, touch, and reduced motion

Keyboard focus shows a flat underline and a focus ring immediately. On touch, a tap plucks the string and the link still navigates. With reduced motion, the underline appears and disappears without moving, and browsers without `linear()`, such as Safari before 17.2, show it flat.

The pluck is hover feedback. Mark the current page with `aria-current="page"` and a style that stays visible without a pointer.
